# Chay ung dung Focus

Tu thu muc goc cua du an, chay:

```powershell
dotnet run --project .\Backend\Backend.csproj
```

Mo http://localhost:5000 trong trinh duyet. ASP.NET Core phuc vu giao dien va API tren cung cong. Du lieu duoc doc/ghi tai `backend-data.json` o thu muc goc.

`server.js` la server Node.js cu va khong can chay khi dung backend C#. Khi kiem thu co the dat bien moi truong `FOCUS_DATA_FILE` thanh duong dan cua mot ban sao du lieu.
